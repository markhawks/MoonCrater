# Contributing

Run `setup/check.sh` before proposing a change. Keep credentials, customer names, inventories,
database exports and operational logs out of commits. Schema changes require a numbered,
idempotent migration in `migrations/` and corresponding documentation.

By submitting a contribution, you agree to license it under AGPL-3.0-or-later, the same license
used by the project. Add a clear description and tests for behavior changes.
